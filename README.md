# 自治体ウェブサイト・公開文書の点検記録

municipal-smr.jpで公開する確認済み記録・集計表の保存と検証用です。
初回移行対象は3分野の10ファイルです。未確認候補、原本、非表示情報の全文、内部パス、個人情報一覧、非公開リポジトリの履歴は含めません。

## 記録

- `records/analysis/akita-website-quality/`: 全国47都道府県の公開状況・確認済み指摘、従来の秋田県記録。
- `records/analysis/akita-public-excel-review/`: Excel、Office、追加調査の集計CSV。
- `records/analysis/municipal-machine-readability/`: 公開済み76資料の得点CSV/JSON、進捗JSON。

サイトのHTML、詳細文書JSON、採点の全指摘、ポータルの下位ページは今回の移行対象外です。原本の再配布・検査ログの公開は個別確認が必要です。

## 検証

`python3 scripts/verify.py` は標準ライブラリだけで動きます。ファイル一覧、Git blob、47県、確認済み指摘のCSV/JSON、76資料の得点、文書検査集計の分母を照合します。原本からの再採点、文書検査、全セル照合、ブラウザー表示検証を代替するものではありません。manifestのハッシュは署名ではなく、変更時はデータとmanifestの両方をレビューします。

記録用のCIはpush/PR時の1ジョブ、最大3分です。これに加え、`workloads/` に公開原本の再採点、ロックされたサイトのビルド・画面検証、施設基準・食品営業の収集・正規化を移行します。各処理はこの公開リポジトリ自身の標準Ubuntuランナーで実行し、非公開側から呼ぶ再利用ワークフローにはしません。非公開トークンや課金AIは使いません。詳細は `workloads/README.md` を参照してください。

## 更新とサイト反映

公開する事実・出典・集計を確認した後、変更のあった記録だけを更新します。時刻だけの更新は避けます。公開側で検証成功した固定コミットを受け取り、サイトの公開用ファイルとsource/publicのミラーを照合したうえで、既存18時の公開工程へ1日1回まとめます。

初回登録は完了しています。サイトへの反映前に、信頼して確認した本スクリプトで固定コミットと成功済みのmain push実行を指定します。

```sh
python3 scripts/site_sync.py --site-root /path/to/municipal-smr-site --public-commit <40桁SHA> --run-id <mainの成功run ID>
```

公開APIから成功したverifyジョブとmanifest・10記録のハッシュを確認し、サイト側の公開ファイルとsource/publicの計20ファイルを比較します。終了0の`unchanged`なら同期用の更新・PR・CIは不要です。終了2の`review_required`なら差分を確認し、既存の生成元も整合させて18時の単一PRにまとめます。その他の失敗では同期を保留します。別の有意なサイト変更をこの判定で抑止してはいけません。

このスクリプトは読み取り専用で、ファイル上書き・公開・CI起動は行いません。公開APIの通信制限時は成功と推定せず保留します。成功証跡やmanifestは原本の正確性や機密性の保証ではありません。未確認候補、原本、非表示の中身を公開せず、更新データとmanifestはレビューします。

保存済みの非公開原本の検証・セキュリティ・公開境界・本番確認は既存工程を維持します。公開側のビルド・画面検証と公開原本再採点は軽量な記録チェックとは別の実処理です。非公開側の省略には入力と成功証跡の一致が必要です。実行先を用意しただけでは削減実績として数えません。

公開先: `gan-stat-app/municipal-public-audits`。本番URLはmunicipal-smr.jpのままです。既存Git履歴をコピーせず新規リポジトリの最初の記録として登録します。
