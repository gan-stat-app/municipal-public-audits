# 全国・施設基準届出アーカイブ

2026年9月の東北医科名簿には、公式Excelでは届出欄が空欄なのにPDFに酸素単価が残る施設が6県30件ある。
正規化前からの媒体差であり、保存済みExcel由来の数値をPDF全件の件数と同一視しない。
原因の照合、対象施設、索引・分析DBへの影響、今後の検証方法は
[調査記録](../../source/analysis/facility-monthly/SOURCE-MEDIA-AUDIT-2026-09.md) を参照。
原入力・集計を推測補正せず、閉院・酸素利用停止と扱わない。

全国8管轄の地方厚生（支）局が公表する施設基準の届出受理資料を月次で棚卸しするための領域です。

- `source-registry.json`: 公式の入口と管轄範囲
- `inventory/<date>.json`: 取得日ごとの構造化ファイルURL、形式、公式ページのSHA-256
- `inventory/latest.json`: 直近の全国棚卸し
- `normalized/<局>/<年月>/`: 都道府県・医科／歯科／薬局別の正規化JSON
- `facility-index.json.gz`: 全国47都道府県の軽量な施設・区分索引（施設名、住所、医療機関番号）

2026年8～9月時点では、北海道厚生局、東北厚生局、関東信越厚生局、東海北陸厚生局、近畿厚生局、中国四国厚生局（中国）、四国厚生支局、九州厚生局の現行名簿について、医科・歯科・薬局の全届出項目を正規化しています。項目別名簿と保険外併用療養費名簿は構造と意味が異なるため、通常の施設基準名簿には混在させません。

Excel、CSV、ZIPを優先します。同内容のPDFは重複取得せず、構造化ファイルがない情報だけを別途検討します。サイト用リポジトリにはリンク台帳と正規化JSONだけを置き、原本バイナリは明示した外部保存先に限って取得します。原本保存と全国共通化は別工程です。列の意味、医療機関番号、基準時点を検証できていない資料は、全国比較用データとして公開しません。

届出名簿は施設基準の受理状況であり、診療実績、病床の稼働、医療の質を示しません。月次差分も新設・廃止とは限りません。

全国索引は届出行を医療機関番号・都道府県・医科／歯科／薬局でまとめた「施設・区分」単位です。同じ施設が複数区分に収録される場合があります。施設カードから届出を開くと、同名施設を混在させないため医療機関番号で完全一致させます。

全国索引は画面表示時には取得せず、利用者が2文字以上入力して全国検索を始めた時点で遅延読込します。配信形式は項目名・都道府県名・管轄名の繰り返しを除いた配列形式です。
