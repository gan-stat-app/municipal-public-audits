# 東北厚生局・届出項目7 月次スナップショット

## 目的

東北厚生局が公表する「施設基準の届出受理医療機関名簿」のうち、届出項目7を月ごとに保存します。現在の名簿を過年度NDBや病床機能報告へそのまま結合せず、各資料の基準時点を確認できるようにするための内部データです。

対象には次の届出が含まれます。

- 地域包括医療病棟入院料1～2
- 地域包括ケア病棟入院料・地域包括ケア入院医療管理料1～4
- 特殊疾患病棟入院料1～2
- 緩和ケア病棟入院料1～2

## 保存内容

- `raw/YYYY-MM/`: 東北厚生局が公表した6県分Excel原本
- `normalized/YYYY-MM.json`: 医療機関・受理番号単位にまとめたデータ
- `diff/YYYY-MM.json`: 直前に保存した基準月との差分
- `index.json`: 基準月、取得日時、原本URL、SHA-256、件数
- `latest.json`: 最新の正規化データ

原本のファイル名に記載された令和年月を基準月とします。取得した年月から基準月を推測しません。公式ページが前月版を掲載したままの場合は、新しい月のデータを生成しません。

## 差分の解釈

差分の「追加」「削除」は、病床の新設・廃止または病院の開設・廃止を直接意味しません。次の事象を含む場合があります。

- 診療報酬改定に伴う再届出
- 入院料区分または受理番号の変更
- 医療機関名・住所等の変更
- 公表資料の訂正
- 届出病床数や加算の変更

病床機能の転換を判定するときは、同じ医療機関番号の前後レコード、算定開始年月日、届出病床数、病床機能報告を併せて確認します。

## NDBとの結合

NDBの年間算定回数と比較する場合、年度内の各月スナップショットから「延べ届出病床月」を算出できます。ただし、届出病床は許可病床、稼働病床、利用病床、患者数のいずれとも同義ではありません。

公開NDBが医療圏集計の場合、複数の病院へ算定回数を配分しません。施設別算定回数として表示することもありません。
