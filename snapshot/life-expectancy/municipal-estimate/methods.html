計算方法と検証結果

厚生労働省の市区町村別生命表の作成方法を基に、取得できる公開入力から計算した参考推計です。四半期死亡数には近似を、一部の入力には独自の例外補完を用いています。

2015年への適用

2020年で確定した地域の事前分布、95歳以上の残余期間、独自例外補完の規則を変更せず、2015年に適用しました。対象は2015年当時の1,888市区町村・男女3,776組です。公式参考値がない福島県8町村を除き、熊本県球磨村は2015年には収録しています。

入力・比較2015年に使用した資料・扱い
死亡・出生死亡は2014～2016年の3年間、出生は2013～2016年。年齢・住所不詳の按分は2020年と同じ手順。
人口2015年国勢調査の日本人・性・各歳人口。後年公開された遡及不詳補完結果を使用。
7～9月の死亡数2015年の市区町村・性・年齢別年間死亡数に、同年の県・性別季節割合を掛けた近似。
階級内の平均生存期間2015年の都道府県・指定都市・東京都区部の各歳生命表。95歳以上も2020年と同じ計算式。
比較対象厚労省の2015年参考値（2020年と同様の方法で算出）。小数1桁のみのため、公表T₀/l₀との高精度比較はできません。

2015年の公式参考値が人口の不詳補完まで再適用したものかは未確認です。統計局は、当初の不詳按分と遡及不詳補完が異なる手法であることを説明しています。この入力処理の違いを残した独自推計です。

地域コードは、滝沢村から滝沢市への市制施行、岩舟町の栃木市への合併、富谷町から富谷市への市制施行を処理しています。表示と人口は2015年の富谷町にそろえ、公式参考表の富谷市と対応させました。

2015年の検証結果

全国3,776組すべてを計算でき、小数第1位は3,053組（80.9％）で公式参考値と一致しました。丸められた参考値との差の平均絶対値は0.031590年、最大は0.302579年（津市・男性）です。丸め幅を考慮しても説明しきれない差があり、人口補完などの入力処理の違いと近似の影響を分離できていません。

独自例外補完が直接必要になったのは、御蔵島村・男性80～84歳と北山村・男性90～94歳です。同じ事前分布を使う東京都区部以外39市町村・男性、和歌山県30市町村・男性の計69組に影響表示を付けています。女性にはこの補完の対象はありません。

出生188ファイルの県合計との一致、死亡の全国値と住所不詳・国外住所との差分、各歳人口の合計を確認しました。再計算キットには全6シナリオの結果を含みます。公式参考値に近づけるための係数の調整は行っていません。

差には公式参考値の最大約±0.05年の丸め幅が含まれます。2020年の平均絶対誤差と同列に比較できません。公式値と近いことは、区間推定の妥当性を示すものではありません。

他の年について

2010・2005・2000年にも公式市区町村生命表はありますが、現在採用している2015・2020年の不詳補完人口をそのまま利用できません。当時の人口按分、死亡・出生の原表形式、市町村合併、95歳以上の処理を検証してから追加を判断します。現時点でこれらの年の独自推計は掲載していません。

2015～2023年について、年次住基人口と３年間の死亡数による別方式の参考推計を掲載しています。既存値の補間ではありません。このページの2015・2020年の比較値とは人口分母・計算法が異なるため、同じ時系列として接続しないでください。

2020年の日本人を対象とし、2021年12月31日の地域区分を基準に比較しました。政令市は各区を単位とし、市全体と区を重複して数えません。1,896市区町村のうち、公式生命表に数値がない9町村を除く1,887市区町村・男女3,774組を収録しています。男女計は計算していません。

計算手順

  1. 地域と不詳値を整える。2018年の那珂川町40305と那珂川市40231の出生数を合算します。死亡は性別に3年間をプールし、年齢のみ不詳を市区町村内の既知年齢死亡数へ比例配分、住所のみ不詳を年齢別に全国の既知市区町村へ比例配分、年齢・住所とも不詳を最後に比例配分します。国外住所の死亡は配分しません。人口は不詳補完結果を用います。按分時の地域母集団には対象外9町村も含む原資料の全地域を使い、事前分布の当てはめ・比較からは9町村を除きます。
  2. 中央人口と分母を求める。国勢調査の10月1日人口を各歳人口と近似した7～9月死亡数で7月1日人口へ補正します。0歳は出生数から作る分母、1歳以上は中央人口の3倍を使います。
  3. 地域の事前分布を求める。県の推定には市町村と政令市・東京都区部の各区を含めます。各区自身の推定には、その指定都市・東京都区部の区を使います。分母で重みを付けた粗死亡率の平均・分散からベータ分布のパラメータを求めます。
  4. 死亡率を安定化する。各市区町村の死亡数・分母と地域の事前分布から事後平均を計算します。人口が小さい地域では地域の情報による安定化が働きます。例外は次節の規則を用います。
  5. 生命表を組み立てる。年齢階級は0歳、1～4歳、5～9歳から90～94歳まで、95歳以上です。推定死亡率を死亡確率へ変換し、生存数・生存延べ年数を積み上げて0歳の平均余命を得ます。95歳以上の残余期間は広域生命表に依存します。
計算式を確認する

P*は10月1日の人口、p*は各歳人口、D̂Qは近似した7～9月死亡数です。Dは按分後の3年間の死亡数、Bᵧはy年の出生数を表します。

P₁₋₄ = P*₁₋₄ + (p*₅ − p*₁)/4 + (31/32)D̂Q₁₋₄ + D̂Q₅₋₉/40
Pₓ = P*ₓ + (p*ₓ₊₅ − p*ₓ)/4 + (39/40)D̂Qₓ + D̂Qₓ₊₅/40  （x=5,10,…,90）
t₀ = (B₂₀₁₈ + 2B₂₀₁₉ + 2B₂₀₂₀ + B₂₀₂₁)/2
tₓ = 3Pₓ  （1歳以上）

rᵢ = Dᵢ/tᵢ,  wᵢ = tᵢ/Σtᵢ
E = Σwᵢrᵢ,  V = Σwᵢ(rᵢ−E)²
k = E(1−E)/V − 1
α = Ek,  β = (1−E)k
m̂ᵢ = (α+Dᵢ)/(α+β+tᵢ)

q₀ = m̂₀
qₓ = n m̂ₓ / {1+(n−aₓ)m̂ₓ}  （n=4または5）
q₉₅₊ = 1
l₀ = 100,000,  dₓ = lₓqₓ,  lₓ₊ₙ = lₓ−dₓ
Lₓ = n lₓ₊ₙ + aₓdₓ,  L₉₅₊ = a₉₅₊l₉₅
Tₓ = Σ（x歳以降のL）,  e₀ = T₀/l₀

aₓは広域の各歳生命表について、当該階級のLの和からn×階級末のlを引き、dの和で割った値です。95歳以上は広域生命表のT₉₅/l₉₅を使います。年間2020年死亡数も年齢・住所不詳を順に按分した後、県・性別の季節比率を掛けます。四半期実数に対する国の按分を再現したものではありません。

例外処理をどう扱ったか

分母と死亡数がともにゼロのセルは事前分布の当てはめに重みゼロで扱い、地域の事前平均を用います。地域全体の死亡数がゼロの年齢階級は死亡率ゼロ、地域の分散がゼロの場合は平均へ退化する境界処理を設けました。通常の計算で前者のセルは7件、地域全体で死亡ゼロは4件ありました。これらの内部実装が国と同一かは未確認です。

さらに、御蔵島村の男性80～84歳、青ヶ島村の男性90～94歳は分母ゼロ・死亡あり、御蔵島村の女性80～84歳は死亡数が近似分母を超えました。厳格に判定すると東京都の区部以外39市町村・男女78組の推定が未解決になります。

公開する独自推計では、この3セルを事前分布の当てはめから外し、当該セルに地域の事前平均のみを使っています。死亡数による更新を見送るモデル変更であり、国の例外処理と同じという意味ではありません。同じ地域の推定を通じて影響を受ける78組すべてに表示を付けます。78組すべてに直接の入力異常があるわけではありません。

2019～2021年の47都道府県・男女282通りで、非重複の市区町村死亡数の合計が県計と年齢別に一致しました。全国残差は住所不詳2,545人と国外住所348人の和に一致し、住所不詳のみを按分しました。

県の事前分布から政令市を除く場合の平均絶対誤差0.043323年、政令市全体を1単位として加える場合の0.016117年に比べ、各区を含める場合は0.005275年でした。今回の公式値との比較から地域区分を検討した探索的検証です。独立した別年での検証を済ませた方法とは扱いません。

利用できる範囲と限界

  • 2020年の参考推計です。別年・任意期間へ同じ精度を保証するものではありません。
  • 国の推計との差は、平均寿命自体の統計的不確実性ではありません。全国の区間推定の校正は未実施です。
  • 四半期死亡の交差表、国の内部の例外実装、丸め前の広域生命表関数は未確保です。国の値に合うよう四半期入力を逆算する合わせ込みはしていません。
  • 推定値の僅かな差による順位や地域の優劣、生活習慣・医療等の原因をこの値だけから判断できません。
