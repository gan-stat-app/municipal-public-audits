# 公開データのRelease保存

2026-11-07の利用者指示により、municipal-smr.jpで既に公開されている数値・派生データを
公開リポジトリのReleasesへ保存する。公開計算・既存サイト・記事の生成条件は変更しない。

public-data-inputs.jsonは非公開repoの履歴をコピーせず、コミット766406bのWorkers exact-path
公開宣言に存在する2,809ファイル・754,755,714 bytesのパス、Git blob、サイズだけを固定する。
17分野のJSON/CSV/GeoJSON/part等。任意期間SMRも今回の利用者承認により含む。
元資料の利用条件・出典は各データ内の記録と https://municipal-smr.jp/data-use/ を参照する。
このアーカイブはデータを改変・独占ライセンス化せず、原本を再取得・再生成したとの主張もしない。
非公開のGit履歴、過去原本、隠れた文書内容、未確認指摘、資格情報は移さない。

公開ジョブは公開サイトだけから匿名取得し、全ファイルのGit blob/サイズを確認する。
SHA-256付きmanifestと128MiB単位の決定的ZIPを作り、同じ公開repoのReleasesへ直接保存する。
Actions artifactへ大容量データをアップロードしない。公開側へ非公開資格情報を渡さない。
JSON等のデータをコードとして実行しない。全入力の確認が終わるまでReleaseは公開しない。
アップロード後にGitHubのSHA-256とサイズを再照合する。部分失敗・HTML fallback・内容変更を成功扱いしない。

mainへのこの変更のpushで一度移行。以後は入力manifest等のレビュー済み変更pushまたは既存手動経路のみ。
PRでは6個の固定応答テストだけを実行し、既存の公開境界・契約テストも保持。新規scheduleなし。
元のpublic-datasets/public-workloadsの統計生成や定期収集は起動・変更しない。
API契約テストの既存旧期待値だけを現在のBatch/手動キー診断経路に同期し、新規API送信は行わない。

公開Releaseの作成は非公開Actions容量の削減完了を意味しない。非公開側は受信・ハッシュ照合・
公開処理の互換性を確認してから重複成果物を削除し、実残存量を測る。0.5GB達成はその実測後にだけ報告する。
